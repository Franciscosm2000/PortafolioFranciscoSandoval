Proyecto destacado · Inteligencia Artificial

Agente de IA para mesa de servicio

Construido en .NET/C# con el SDK de OpenAI y en producción desde 2026: un asistente que entiende solicitudes en lenguaje natural y las convierte en acciones reales sobre los sistemas de la empresa: ERP, SQL Server, APIs internas y servidores.

Demo: consultas y acciones operativas mediante lenguaje natural.

Cómo funciona

  1. Solicitud en lenguaje natural. Desde un portal web interno, el usuario escribe lo que necesita como se lo pediría a una persona.
  2. Interpretación con OpenAI. El agente identifica la intención y elige la herramienta adecuada.
  3. Ejecución sobre sistemas reales. Consulta el ERP y SQL Server, llama APIs internas o revisa servidores.
  4. Confirmación para acciones críticas. Antes de modificar algo, pide aprobación explícita.
  5. Respuesta clara. Devuelve el resultado al usuario; la operación se monitorea de forma continua.

Consultas al ERP

Pedidos, estados y procesos empresariales consultados en lenguaje natural, sin navegar pantallas ni escribir SQL.

Monitoreo de servicios

Verificación del estado de servicios Windows, interfaces y workers desplegados en servidores.

Automatización operativa

Cambios de estado, apertura de nuevos días operativos y ejecución de procesos a través de APIs.

Ahorro de tiempo

Consultas repetitivas que tomaban minutos se resuelven en segundos; el equipo lo usa más de 10 veces al día.

Seguro por diseño

Confirmación previa para acciones críticas y operación productiva con monitoreo continuo.

Integración ERP Infor LN ↔ XSales

Problema
Con la migración de la plataforma de fuerza de ventas XSales a SaaS, clientes, inventarios, pedidos y rutas debían mantenerse consistentes con el ERP Infor LN.
Solución
Diseño e implementación de la capa de integración con APIs, Worker Services y customizaciones sobre Infor LN para la sincronización y automatización de procesos comerciales y operativos.
Resultado
Más de 6 procesos y entidades comerciales sincronizados automáticamente entre ERP y SFA.
Infor LN XSales SaaS ASP.NET Core Worker Services SQL Server

Performance tuning en SQL Server

Problema
Procedimientos almacenados críticos con tiempos de ejecución superiores a 30 minutos.
Solución
  • Análisis de planes de ejecución: scans innecesarios, key lookups y operadores costosos.
  • Reescritura con CTE, operaciones basadas en conjuntos y eliminación de cursores.
  • Índices estratégicos, tablas temporales y segmentación para cargas de alto volumen.
Resultado
Ejecución reducida de más de 30 minutos a menos de 5 minutos.
SQL Server Execution Plans Indexación

Autenticación centralizada

Problema

Solución
Autenticación centralizada con Active Directory, JWT y APIs compartidas consumidas por todos los portales.
Resultado
Más de 6 portales corporativos con un único punto de autenticación.
Active Directory JWT ASP.NET Core
